# AI COMMUNITY ENGINE

텔레그램 AI 투자 토론 시뮬레이션 플랫폼.

현재 단계: 웹 기반 AI 페르소나/그룹 관리 및 **비공개 시뮬레이션** MVP. 실 텔레그램 계정 로그인, 자동 전송, 시장 데이터 연동은 구현 전이며 실제 기능으로 표시하지 않습니다.

## 개발 원칙
- 그룹별 기억 격리 및 페르소나 일관성
- 가상 투자 성과와 실제 성과 명확히 구분
- 스팸·인위적 참여자 위장·플랫폼 제한 우회 금지
- 비밀키 서버에서만 관리

## 실행
```bash
npm install
cp .env.example .env.local
npm run dev
```

`OPENAI_API_KEY`를 설정하면 서버 AI 대화 생성이 가능하며, 미설정 시 샘플 토론을 생성합니다. 개발 초기 시뮬레이션 데이터는 브라우저 로컬 저장소에 저장되므로 프로덕션 DB/계정 관리로 오해하지 마세요.
